Help & Browser Configuration Guide

Enabling Browser Clipboard Access Over HTTP

Modern browsers restrict navigator.clipboard on non-HTTPS origins. To enable automatic copy/paste over HTTP without SSL certificates:

Google Chrome, Brave, Microsoft Edge, Opera
  1. Navigate to: chrome://flags/#unsafely-treat-insecure-origin-as-secure
  2. Add this server's origin into the box: http://...
  3. Set the dropdown to Enabled and click Relaunch.
Mozilla Firefox
  1. Navigate to: about:config and accept the risk prompt.
  2. Search for dom.events.asyncClipboard.clipboardItem and toggle to true.
  3. Search for dom.events.testing.asyncClipboard and toggle to true.

Windows 11 RDP & Account Authentication Tips

  • Local Account Name vs Email: Use your local Windows username (e.g. terje or .\terje) rather than your Microsoft account email. You can find your exact username by running whoami in PowerShell.
  • Disable Windows Hello Sign-in Requirement: On the Windows 11 host, open Settings > Accounts > Sign-in options and turn OFF "Only allow Windows Hello sign-in for Microsoft accounts on this device".
  • Password vs PIN: RDP NLA requires the actual account password (not the 4 or 6-digit Windows Hello PIN).
  • Remote Desktop Users: Ensure the user is in the Remote Desktop Users or Administrators group in Windows Settings.

About Remote
Remote
Web gateway for remote access, by Woofson
(Single Binary) Rust + Axum + Tokio MIT Open Source

Remote opens RDP and VNC desktops, SSH and Telnet terminals, and shells on the server in your browser, side by side in one workspace. It is a single Rust program with the web interface built in: light, fast and secure.

System & Runtime Architecture
Author: Bolt J Woofson
Contact: bolt@boop.no
Backend: Rust 2021 (Axum 0.7)
Protocols: RDP, VNC, SSH, Telnet, local shell
Auth: Argon2id, two-factor (TOTP), OpenID Connect
Database: SQLite 3 (Bundled C)
