About Remote
Remote
Ultra-Low-Resource Remote Gateway — By Woofson
v0.2.0 (Single Binary) Rust + Axum + Tokio MIT Open Source

Remote is an ultra-high-performance, memory-safe alternative to Apache Guacamole. Built in modern Rust with pure HTML5 Canvas and WebSockets, Remote delivers RDP, VNC, and SSH multi-pane access with native clipboard auto-sync and SFTP dropboxes using a fraction of traditional gateway resources.

System & Runtime Architecture
Author: Bolt J Woofson
Contact: bolt@boop.no
Backend: Rust 2021 (Axum 0.7)
Protocols: RDP, RFB/VNC, SSH, Local PTY
Auth: Argon2id + JWT + Authentik OIDC
Database: SQLite 3 (Bundled C)
Repository: github.com/Woofson/remote
License: MIT License
